# VLAN Receptionist Network Lab

## 📌 Objective
Configure a VLAN-based network separating Receptionist (VLAN 10) and finance office (VLAN 20) devices while maintaining connectivity between them.

---



## 📋 Device Inventory

|--------|------------|------|------|
| Laptop0 | 192.168.10.11 | 10 | Receptionist Laptop |
| PC0 | 192.168.10.12 | 10 | Receptionist Desktop |
